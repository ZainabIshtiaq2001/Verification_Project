 
////////////////////////// AMBA: Advanced Microcontroller Bus Architecture//////////////////////


AMBA: Advanced Microcontroller Bus Architecture
 AHB: Advanced High-performance Bus
 APB: Advanced Peripheral Bus
 HADDR: AHB Address (The bus used by the master to send the memory address)
 HWDATA: AHB Write Data (The bus used by the master to send data to a slave)
 HRDATA: AHB Read Data (The bus used by a slave to send data back to the master)
 HSEL: AHB Select (The signal used to activate or "select" a specific slave)

(Note: In AMBA AHB signal names, the prefix "H" simply denotes that the signal belongs to the High-performance Bus).



///////////////////////Mater///////////////////////////



Meaning of the Signal Abbreviations In the AMBA AHB protocol, all signals are prefixed with an "H" to denote they belong to the High-performance bus (AHB).
HCLK: AHB Clock
HRESETn: AHB Reset (The 'n' stands for negative/active-low)
HREADY: AHB Ready (Indicates completion of a transfer)
HRESP: AHB Response (Status of the transfer)
HADDR: AHB Address
HWRITE: AHB Write (Control signal for read vs. write)
HSIZE: AHB Size (Size of the data payload)
HBURST: AHB Burst (Type of data burst sequence)
HPROT: AHB Protection (Privilege and memory protection state)
HTRANS: AHB Transfer type (State of the bus: Idle, Sequential, etc.)
HMASTLOCK: AHB Master Lock (Locks the bus for an exclusive sequence)
HRDATA: AHB Read Data
HWDATA: AHB Write Data
